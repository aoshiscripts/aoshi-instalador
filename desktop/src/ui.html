Abas vinculadas

Cada proxy fica preso a uma aba só. Fechar a aba não desfaz o vínculo: abra de novo por aqui e ela volta com o mesmo proxy, o mesmo nome e a última página.

Scripts de usuário

Rodam em todas as abas, cada uma pelo próprio proxy. Os dados de cada script ficam separados por proxy. Também dá para abrir um link .user.js numa aba: o programa instala por aqui.

Nova aba

Escolha o proxy desta aba. Abas com proxies diferentes têm cookies e login separados.

Proxies

Formato: endereço:porta:usuário:senha (usuário e senha são opcionais). Cada proxy tem os seus cookies: use um em cada aba. Os proxies novos são testados sozinhos: país, IP e latência até o Tribal Wars.
